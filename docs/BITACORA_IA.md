## Categorías que conviene cubrir (mínimo un ejemplo de cada una)

1. **Generación de código:** entidades, controladores, componentes Angular.
2. **Depuración:** pega un error real (CORS, 401, conexión a BD) y documenta el diagnóstico.
3. **Documentación automática:** pide comentarios JavaDoc/TSDoc y el README.
4. **Refactorización:** pide mejorar nombres, separar capas o eliminar duplicación.
5. **Explicación de código:** pide que explique un fragmento que no entiendas.

## Ejemplos de prompts útiles
- "Genera una entidad JPA `Task` con título, descripción, estado, prioridad y fecha límite, relacionada con `User`."
- "Este error aparece al llamar la API desde Angular: [pegar error]. ¿Cuál es la causa y cómo lo corrijo?"
- "Agrega JavaDoc en español a todos los métodos públicos de este servicio."
- "Haz esta pantalla responsive para móvil sin usar librerías externas."
